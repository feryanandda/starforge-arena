STARFORGE — an original arena game. Ten waves of swarm are coming for the last forge in the dark; you are its keeper. Fly with WASD or arrows, aim with the mouse, hold click or Space to fire, Shift to dash. Five enemy kinds (drones, weavers, splitters, spitters and the Forgebrute on waves 5 and 10), combo scoring, cores and hull shards to grab, and a forge shop between waves that offers one of three upgrades — hotter bullets, a split barrel, a thicker hull, an ion engine, a core magnet. Clear wave 10 to win, then keep the fire alive in endless mode. All art is drawn in code, all sound is synthesised with WebAudio; the game is plain static files and runs offline.

## Run it

```sh
node serve.ts   # then open http://localhost:8080 — or serve game/ with any static server
```

Hand in with `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
